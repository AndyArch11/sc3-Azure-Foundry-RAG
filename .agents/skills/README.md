# Assessment Skill Pack

This directory contains standards-based Agent Skills for the assessment orchestration domain.

## Layout

Each skill is a folder with a `SKILL.md` file.

- `trigger-intake`
- `content-resolution`
- `access-validation`
- `content-retrieval`
- `corpus-retrieval`
- `assessment`
- `delivery-decision`
- `publication`
- `audit-and-trace`

## Source of truth

The `SKILL.md` files in this directory are the canonical skill definitions.

## Standards basis

This pack follows the open Agent Skills format:

- one folder per skill
- required `SKILL.md`
- required YAML frontmatter fields `name` and `description`
- Markdown instructions for predictable agent execution
